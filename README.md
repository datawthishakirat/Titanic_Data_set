# Titanic Survival Analysis 🚢

### Project Overview
This project is an Exploratory Data Analysis (EDA) for the Titanic dataset. My goal was to identify the key features that determined passenger survival.

### 📊 Key Insights
* **Survival Rate:** 61.6% perished, while 38.4% survived.
* **The Gender Rule:** Female passengers had a massive survival advantage (74% vs 19% for males).
* **Socio-Economic Impact:** 3rd Class passengers aged 20-35 faced the highest mortality rates.
* **Age Factor:** A clear 'survival hump' exists for children aged 0-10.

### 🛠 Tools Used
* Python, Pandas, Seaborn, Matplotlib
